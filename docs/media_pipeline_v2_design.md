# 媒体管线设计

StoryForge 的媒体管线围绕三个核心资源运行：角色定妆图、场景母图和 segment 视频 prompt。系统不生成额外静态关键帧；视频连续性通过场景母图、上一段视频尾帧和 prompt 合同共同控制。

## 设计目标

- 角色身份稳定。
- 场景空间稳定。
- 分段视频可单独生成、审阅和重做。
- 同一空间内尽量减少画面跳变。
- 新地点明确建立新的环境基准。
- 每次 provider 提交都有可审计的 prompt、payload 和参考图绑定。

## 资源类型

### 角色定妆图

角色图是单角色白底三视图。它用于锁定脸、发型、服装、体型和年龄感。

角色图不描述剧情状态，不作为视频时间锚点。

### 场景母图

场景母图是无人物、无文字的环境参考图。它用于锁定地点、空间透视、光线、背景锚点和固定道具。

场景母图不承载角色动作，也不是视频时间帧。

### 上一段视频尾帧

上一段视频尾帧来自 Seedance 返回的 `last_frame_url`。它只在需要连续承接时提交，用于锁定当前片段开头的构图、角色站位、动作停点和光线状态。

尾帧不是场景母图，不能替代环境基准。

### 视频 Prompt

视频 prompt 描述当前 segment 的连续表演。它包含：

- 时长。
- 开场状态。
- 角色运动轨迹。
- 镜头调度。
- 收束状态。
- 对白、音色、环境音、音乐和字幕。
- 连续性保护。

## Seedream 管线

Seedream 负责角色图和场景母图。

角色图提交：

- 单角色。
- 白底三视图。
- 同一项目内统一画风、线条、上色和光照。
- 只允许角色姓名作为可见文字。

场景母图提交：

- 无人物空场景。
- 不包含文字、Logo、水印和说明性排版。
- 明确地点、时间、天气、光线、空间布局、主色调、背景锚点和固定道具。
- 同空间推进时可参考上一 scene 母图。
- 新地点必须建立新母图。

## Seedance 管线

每个 segment 对应一个 Seedance clip。

提交内容：

- `reference_images`：场景母图、可选上一段尾帧、实际出镜角色图。
- `submitted_reference_bindings`：每张图的用途说明。
- `prompt`：最终 Seedance prompt。
- `duration`、`resolution`、`watermark` 等 provider 参数。
- `return_last_frame`：请求 provider 返回尾帧供后续片段承接。

最终 prompt 必须按真实提交顺序写清图片用途。业务逻辑不得假设角色图永远从 `图片2` 开始。

## 连续性策略

### 同一 scene 内

后一个 segment 优先使用前一个 segment 的尾帧作为开场参考。prompt 会要求先对齐尾帧构图和动作停点，再在场景母图空间内推进。

### 同一空间跨 scene

当 scene 被明确标记为同一空间推进或同地点新角度时，可以复用或承接上一 scene 的场景母图，并在可用时承接上一段尾帧。

### 新地点

新地点不复用上一 scene 母图。下一场首段视频负责建立新地点，不强行把上一空间变形接入。

### 过渡空镜

过渡空镜不是默认流程。只有明确需要“过渡空镜”时，才额外生成 transition clip。

## 审片数据

分段审片台展示当前 segment 的关键事实：

- 视频或待生成状态。
- 场景母图。
- 出镜角色图。
- 可用尾帧状态。
- 基础视频 prompt。
- 含图片编号绑定的提交 prompt。
- 真实请求 payload。
- 连续性问题和修复入口。

## 失败处理

常见失败分三类：

- 资源未就绪：缺场景母图、角色图或视频 prompt。
- provider 失败：Seedream 或 Seedance 返回错误、超时或缺少结果 URL。
- 连续性失败：规划合同不满足时长、对白、动作容量、多人镜头或空间承接要求。

资源未就绪应先补齐上游产物。provider 失败应保留请求 payload 便于重试。连续性失败应先修复合同，再重跑媒体阶段。
