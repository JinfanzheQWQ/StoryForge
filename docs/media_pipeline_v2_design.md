# 媒体管线设计

StoryForge 的媒体管线以 scene 级场景母图、角色定妆图和 segment 级 motion prompt 驱动视频生成。

## 目标

- 场景母图负责稳定环境。
- 角色图负责稳定人物身份。
- 视频 prompt 负责描述角色在环境中的运动、镜头、声音、字幕和收束。
- 每个 segment 都能独立审阅、修改和重做。
- 同一连续空间内尽量通过场景母图复用和上一段视频尾帧承接降低跳变。

## 参考图类型

### 场景母图

场景母图是无人物、无文字的环境参考图，用于锁定地点、空间透视、光线、背景锚点和固定道具。

### 上一段视频尾帧

上一段视频尾帧只在需要连续承接时提交，用于锁定当前片段开场构图、角色站位、动作停点和光线状态。

### 角色图

角色图是单角色白底三视图，用于锁定脸、发型、服装、体型和年龄感。角色图不是视频时间锚点。

## Seedance 提交

每次提交都会生成明确的参考图绑定说明。业务逻辑以 `submitted_reference_bindings` 为准，不依赖固定图片编号。

提交内容包括：

- 参考图 URL 列表。
- 与参考图顺序对应的绑定说明。
- Seedance motion prompt。
- 时长、分辨率、水印等 provider 参数。

## 连续性策略

- 同一 scene 内，后一个 segment 优先承接前一个 segment 的尾帧。
- 明确同一空间推进的相邻 scene 可以继承场景母图并承接上一段尾帧。
- 新地点、空间关系变化明确或连续性不确定时生成新的场景母图，并从新场景开场。

## 页面审阅

分段审片台按当前 segment 展示：

- 场景母图。
- 角色图。
- 视频。
- motion plan。
- 最终 prompt。
- 真实请求 payload。
- 参考图绑定。
- 状态、失败原因和重做入口。
