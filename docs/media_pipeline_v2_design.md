# 媒体管线设计

StoryForge 的媒体管线围绕四类核心资源运行：角色定妆图、场景母图、九宫格分镜图和 segment 视频 prompt。九宫格分镜模式先把每个 segment 物化成一张 3x3 连续分镜图，再把这张图作为 Seedance 的主要视频参考图；如果规划判断当前段需要承接上一段，会额外提交上一段尾帧。连续表演模式则直接使用场景母图、角色图、可用尾帧和 prompt 生成视频。

## 设计目标

- 角色身份稳定。
- 场景空间稳定。
- 分段视频可单独生成、审阅和重做。
- 同一空间内尽量减少画面跳变。
- 新地点明确建立新的环境基准。
- 视频提交前可以先审阅每段的动作关键帧。
- 每次媒体提交都有可审计的 prompt、payload 和参考图绑定。

## 资源类型

### 角色定妆图

角色图是单角色白底三视图。它用于锁定脸、发型、服装、体型和年龄感。

角色图不描述剧情状态，不作为视频时间锚点。

### 场景母图

场景母图是无人物、无文字的环境参考图。它用于锁定地点、空间透视、光线、背景锚点和固定道具。

场景母图不承载角色动作，也不是视频时间帧。

### 上一段视频尾帧

上一段视频尾帧来自 Seedance 返回的 `last_frame_url`。九宫格模式下，尾帧不参与九宫格生图，只在当前视频需要承接上一段时作为 Seedance 的第二张参考图和 `first_frame` 提交。连续表演模式下，尾帧可直接提交给 Seedance，用于锁定当前片段开头。

尾帧不是场景母图，不能替代环境基准。

### 九宫格分镜图

九宫格分镜图是一张 3x3 连续动作图。它把 segment 的 timed beats、对白、角色运动、镜头关系和收束状态展开为固定 9 个格子，形成可审阅的视觉蓝图。

九宫格生成输入：

- 当前 scene 的场景母图。
- 实际出镜角色的角色图。
- segment 标题、摘要、timed beats 和对白。

九宫格输出后会同步到 `seedance_manifest.json`，并重置当前 segment 的旧视频结果，避免视频继续引用过期分镜。

### 视频 Prompt

连续表演模式的视频 prompt 描述当前 segment 的连续表演，包含：

- 时长。
- 开场状态。
- 角色运动轨迹。
- 镜头调度。
- 收束状态。
- 对白、音色、环境音、音乐和字幕。
- 连续性保护。

九宫格模式的视频 prompt 只描述如何根据九宫格分镜图生成连续视频，对白直接写进对应 `场景N ({start}-{end}秒): ...` 描述，不再单独输出音频规则块。

## 生图管线

角色图、场景母图和九宫格分镜图都通过统一生图管线生成。每次提交前可选择 `GPT Image 2` 或 `Seedream 4.5`，并选择当前模型支持的分辨率和比例。后端按任务 payload 中的 `image_model` 路由到对应模型，不复用不同模型配置下的旧任务。

角色图提交：

- 单角色。
- 白底三视图。
- 同一项目内统一画风、线条、上色和光照。
- 只允许角色姓名作为可见文字。

场景母图提交：

- 无人物空场景。
- 不包含文字、Logo、水印和说明性排版。
- 明确地点、时间、天气、光线、空间布局、主色调、背景锚点和固定道具。
- 同一 scene 内多个 segment 共用当前 scene 母图。
- 同空间跨 scene 推进时，上一 scene 母图只作为参考图输入，用来生成当前 scene 的新母图。
- 新地点必须建立新母图。

## 九宫格管线

每个 segment 对应一个 `StoryboardGridTask`。

提交内容：

- `reference_images`：场景母图、实际出镜角色图。
- `prompt`：九宫格分镜 prompt，固定描述格1到格9的动作演进。
- `storyboard_scene_descriptions`：按 `格N ({start}-{end}秒): {beat_description}` 生成的九格时间描述，每格明确起始/推进/结果关键帧、景别、站位、视线或构图差异；对白直接写入对应格子。
- `request_info`：真实生图请求、参考图绑定和响应摘要。

生成后写入：

- `storyboard_grid_manifest.json`
- `assets/storyboards/{segment_id}_grid.*`

## Seedance 管线

每个 segment 对应一个 Seedance clip。

九宫格模式提交内容：

- `reference_images`：九宫格分镜图；需要承接上一段时额外包含上一段视频尾帧。
- `submitted_reference_bindings`：`图片1` 是九宫格分镜图，`图片2` 可选为上一段视频尾帧。
- `prompt`：按九宫格分镜图生成视频的场景时间描述。

连续表演模式提交内容：

- `reference_images`：场景母图、可选上一段尾帧、实际出镜角色图。
- `submitted_reference_bindings`：每张图的用途说明。
- `prompt`：最终 Seedance prompt。
- `duration`、`resolution`、`watermark` 等提交参数。
- `return_last_frame`：请求视频服务返回尾帧供后续片段承接。

最终 prompt 必须按真实提交顺序写清图片用途。九宫格模式必须把九宫格作为 `图片1`，需要尾帧承接时把上一段尾帧作为 `图片2`；连续表演模式不得假设角色图永远从 `图片2` 开始。

## 连续性策略

### 同一 scene 内

后一个 segment 优先使用前一个 segment 的尾帧作为开场参考。九宫格模式的视频阶段会同时提交九宫格和尾帧，要求 Seedance 先对齐尾帧构图和动作停点，再按九宫格推进；九宫格生图本身不使用尾帧。连续表演模式会要求 Seedance 先对齐尾帧构图和动作停点，再在场景母图空间内推进。

### 同一空间跨 scene

当 scene 被明确标记为同一空间推进或同地点新角度时，当前 scene 会参考上一 scene 母图生成新的派生母图，并在可用时承接上一段尾帧。跨 scene 不直接复制上一张母图 URL。

### 新地点

新地点不复用上一 scene 母图。下一场首段视频负责建立新地点，不强行把上一空间变形接入。

### 过渡空镜

过渡空镜不是默认流程。只有明确需要“过渡空镜”时，才额外生成 transition clip。

## 审片数据

分段审片台展示当前 segment 的关键事实：

- 视频或待生成状态。
- 场景母图。
- 九宫格分镜图。
- 出镜角色图。
- 可用尾帧状态。
- 九宫格 prompt 和基础视频 prompt。
- 含图片编号绑定的提交 prompt。
- 真实请求 payload。
- 连续性问题和修复入口。

## 失败处理

常见失败分三类：

- 资源未就绪：缺场景母图、角色图、九宫格图或视频 prompt。
- 媒体服务失败：Seedream 或 Seedance 返回错误、超时或缺少结果 URL。
- 连续性失败：规划合同不满足时长、对白、动作容量、多人镜头或空间承接要求。

资源未就绪应先补齐上游产物。媒体服务失败应保留请求 payload 便于重试。连续性失败应先修复合同，再重跑媒体阶段。
